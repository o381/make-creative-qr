# 创意构成、外观审查与失败诊断

## 制作前：让分布有来历

用三句话说明独立成立的事件或抽象规则、承载信息的形成机制、与上一款至少两处构成差异。题材名称不能代替构成：换角色或物体，仍保留中央方阵加三个特殊团块，属于重复布局。

自然感来自材料和空间的关系，不等于照片质感，也不等于随机噪声。允许夸张、幻想和二维画面，但材料的聚散、接触、运动或层叠应服从画面自己的规则。不要为一块现成编码补写故事。

当任务要求信息像偶然出现在场景中时，区分“事件发生”与“用摆件说明事件”。一条连接材料或一个诗意标题，不能解释另行塑形的道具、规整间距或刻意裁出的轮廓。渲染纹理前先问：什么可见动作或物理过程形成了这些分布？这项判断独立于正确投影和真实材质。手工摆设可以适合其他创作方向，但不默认等于自然发生的场景融合。

在构建导引图前检查三个尺度：

| 尺度 | 要设计什么 | 常见伪自然 |
| --- | --- | --- |
| 整体 | 来源、去向、主次、疏密、边界与事件关系 | 中央是一块矩形编码，角色在旁边，四周加装饰。 |
| 团块 | 大小变化、聚合与分散、方向及接触关系 | 三个角各一块同规格团块，或凭空增加同款团块作掩护。 |
| 细节 | 粒径、边缘、空隙、光泽与材料连续性 | 在固定码形上加毛边、颗粒和噪声，构成仍完全相同。 |

精确信息位置不能随意随机化。通过合法分组、当前内容的新矩阵、整场布局以及安全外围的合理延续探索构成；每次改变都重新验证。

生成前核对载体自然细节的尺度和主方向能否承载所需信息。将功能区尺寸与普通材料特征单独比较，不能只看数据细部：真实纹理也遮不住三处明显过大的图案。尺度冲突时可选择合法的新编码或布局，随后重验完整实际文件，不能假设矩阵更密仍然可读。例如宽大的放射状布褶不自动支持横纵双向的密集变化。拟合矩阵或最小化像素改动之前，先划清实际材料所在：空雾、纸面或背景可能数值代价低，却会让编码变成凭空新增的点阵；这种位置应在优化前排除。模型可能通过删除不受材料支持的变化来换取可信材质。出现这种情况时，对照实际几何与导引，不用平面亮度补丁强塞回信息。选择能合理形成所需细部的机制，再验证实际渲染结果。

## 比较作品：提炼差异，不复制布局

以下是可迁移的比较方法，不是成功配方：

- 疏密过渡、大小不同的团块和跨越编码区内外的同类细屑，可能降低专设码面的感觉；前提是它们服从同一形成机制，必要明暗间隙得到保护。
- 光滑且厚重的连续轮廓、近似均匀的线宽和规则空洞，容易让整体像一块设计好的图案。连续材料本身并不失败；检查它是否暴露了矩形主体和模块节奏。
- 毛边或粉末可以弱化局部轮廓，却可能保留同一方形密集区。不要把纹理变复杂误认为构成变自然。
- 用几条细线、尾巴或支流连接定位区，只改变连通性；如果三处位置、避让空间和主信息区边界仍显眼，继续重构。
- 除三处定位区外加入相似团块不是自动解法。没有材料来历、密度过渡或场景关系的陪衬，可能使整张图更刻意。
- 材料自然与事件清楚是两个判断。更换材质后重新检查动作、接触和材料行为是否相互解释；不能只保留更粗糙的表面，却丢掉清楚的事件关系。

保留用户的比较层级。“第一张比第二张自然，但第一张仍刻意”包含偏好和保留意见，不能概括成“第一张已自然融入”。提炼有帮助的机制，同时写出尚未解决的结构缺陷。

## 成图：先看整体，再看细节

看完整画面和约 320 像素宽缩略图，再放大检查材料。缩略观察只用于外观，不能替代扫码测试。依次判断：

先隐藏标题与创作解释判断缩略图。若精细材质干扰了构成判断，可另看简化为三个明暗层级的缩略图，检查密度边界和三处异常突出的特征。这个辅助视图只诊断构成，不能批准解码，也不能替代实际作品审查。材质精修不能使此前被否定的分布绕过这一检查。

1. **独立成立：** 不提扫码，观看者能否理解事件、材料为何出现、如何分布？抽象画面是否有自己的构成逻辑？
2. **没有专设码面：** 整体是否仍像矩形密集图案，接几条外伸线、换毛边后也一样？外围是否只负责装饰？不能裁掉场景来规避。
3. **三个角没有特殊待遇：** 比较左上、右上、左下与全场的尺寸、锐度、灰度、空隙及周围细屑。三处独有的团块、卫星点、模糊阴影、图标、圆环或清空区均须修订；形状不方也一样。
4. **区内外连续：** 材料、粒径范围、厚度和光泽是否一致，密度是否有合理过渡？中央细小平面码点、外围全是立体大块仍会暴露信息区。
5. **元素完整：** 花色、字符、几何图形或角色是否被拉成无意义的黏连怪形？无法兼顾自身形态与编码时，换承载机制。
6. **不同款真的不同：** 忽略背景和配色，形成机制、聚散、方向、边界和场景关系是否改变？仅换 mask 或角色不能证明新创意。
7. **材质与光学可信：** 独立于扫码检查接触、遮挡、光向与投影。实体应有合理支撑及符合照明的接触阴影；投射或折射光应服从承接表面，不能像浮起的涂层一样有自身厚度。按原尺寸检查纹理与边缘是否涂抹、起光晕或丢失细节；缩略图可信不能证明材质清晰。微观结构应服从材料：颜色边界不应各自改变毛发、纤维或表面纹理的铺向；放射状毛团或局部纹理改向，即使像素锐利仍可能很假。

保护或移动身体结构时，选区应沿实际元素轮廓。宽泛选区可能把背景像素带进另一表面，制造假孔洞，也会高估必须保护的编码误差。先检查合成材质，再把该选区当作编码约束。已知几何允许诊断误差预算时，分别统计每个纠错块中受损的码字和功能区损伤；总面积小或平均模块符合率高，仍可能掩盖某个块已超限。将此检查放在再次重绘或编码拟合之前。已知几何采样只指导修订，不能批准作品。

任一项失败，记录具体位置和关系。整体边界、事件或分布失败时回到构成；仅材质细节失败时做小步编辑。不要在同一主体布局上连续换皮。请求手机复测之前也执行此审查：任务是完成自然作品时，已知可见方阵或三个加工靶标须退回创作，即使软件稳定性有所提高。“诊断稿”标签不能改变这一决定；用户主动要求的调查预览仍可分享。

色调修订后，检查表面是否看起来改变了形状：平滑亮度场即使保留原像素锐度，也可能将尖锐褶面变成软凹坑，或制造三个鼓起的靶标。跨色素变化移用细纹理时，应区分材料颗粒与旧色素边界：高频残差可能把旧图案作为重影带回来。修订或重绘应服从实际表面边界与材料行为。像素清晰或像素改动代价小，都不能单独证明材质没有编辑感；须在场景中检查被改动的结构，再次完成外观审查和完整验码。

色彩承载信息时，对比调色或亮度归一化前后的完整构成。层次压平、颜色发灰、仍有边界的淡码面，即使改善解码也属于外观失败。压低对比度本身不等于融合；继续对比度或密度实验前先看缩略图。

## 反馈与案例资格

在任务私有记录中分开保存以下状态，绑定实际文件及哈希或经宿主保证的不可变资产版本：

| 状态 | 可记录的证据 | 不能据此推定 |
| --- | --- | --- |
| 相对偏好 | 用户喜欢哪张、比较顺序、仍指出的缺陷 | 该张已通过外观验收。 |
| 外观判断 | 整图审查结果和用户具体反馈 | 能扫描，或已经手机实扫。 |
| 软件资格 | 当前完整文件与全部预定变体的真实解码记录 | 手机 App 必能扫描。 |
| 手机证据 | 用户或实际执行的扫描反馈、文件、方式 | 另一版本、下一张或其他扫描方式也通过。 |

喜欢或“收下”但未完成全尺寸验证的图，可留作视觉参考，不能收进可扫码展示案例。重新上传即对该份实际文件重新验证。用户手机失败具有否决权，软件通过不能覆盖。

手机已否定的版本，若在可用的独立解码器或小幅整图近似拍摄诊断中也存在可复现失败，应把相关失败带入修订版的回归检查。旧尺寸组合通过，不能成为在同样失败仍存在时再次请求手机复测的充分理由。保留能读的诊断修复作为因果对照，不能因此允许交付显眼的定位符号。

收到手机失败反馈后，保留失败文件及扫码方式作为回归案例。在私有诊断中对比“只修功能区”和“只修数据区”，区分定位失败与内容恢复失败；带明显定位符号的诊断图不是交付物。简化定位形象时，同时检查完整轮廓、外侧浅色分隔和中央剖面；只有十字剖面能读，不能证明定位稳定。同一解码器通过多个尺寸仍可能共享一种定位弱点。能力允许时，用独立实现及小幅整图旋转、近似拍摄退化检查修订版，记录分歧，手机状态保持未解决直到复测。这些诊断补充原验收项，不能替代手机实扫，也不能成为恢复三个显眼靶标的理由。

## 从失败选择修订

| 观察或证据 | 下一步 |
| --- | --- |
| 导引图通过，实际成图全失败 | 比较整场比例、偏移、模块中心及功能区灰度；先修复信息偏差，停止堆背景细节。 |
| 重绘复制了材质参考的旧分布，没有遵从信息导引 | 移除相互竞争的完整分布，或只提供材质细节参考；目标图未改动的周边也可能已能提供所需材质。重新核对实际空间关系，不能只看纹理是否变好。 |
| 数据中心大致正确，整图不能检测 | 检查暗核、浅色间隔、灰度边缘及高光、阴影。中心正确和平均灰度近似不能证明可扫。 |
| 粉末或排线版更自然但解码失败 | 检查颗粒侵入浅色带、排线掏空暗核或密度改变。保留其视觉经验，不能称为成品。 |
| 高纠错仍不能检测，或仅原图通过 | 回到功能轮廓、间隙和显示尺度，不继续只靠升版本或纠错级别碰运气。 |
| 环状版能扫，拆散后失败 | 保留技术回退，不把环状版当自然成功；改承载机制并复测，不直接删功能信息。 |
| 整块替换定位区有效，但原有暗核和浅色间隙外观已可接受 | 先在诊断对照中分别隔离外侧包围轮廓、暗核、浅色间隙及外部留白，再决定重画范围。整块修复不能证明每部分都有必要改变；证据支持时保留原有材质。 |
| 只有部分尺寸或压缩版本通过 | 保持生成前的必测项。证据指向功能轮廓时，先在私有诊断中分别隔离区域或轮廓段，再组合修复：同一改动可能改善一个尺度却破坏另一个。复审外观，再对实际新文件与全部预定变体完整复验。 |
| 扫码修复使三个角或方阵重新突出 | 再做外观审查；回到布局、形成机制或材料选择，不能以技术成功结束。 |
| 图片改动、复制损坏或哈希变化 | 停止交付与保存，重新导出、完整解码、重新绑定报告。 |

图像模型可能放大信息区、裁掉外围、把多颗粒概括成大符号。提示词“严格保持”不是验证结果。SVG 修正导引图是技术资料，不是艺术成品；裁剪、已知四角或纯码检测也不能批准交付。

整图角度、信息比例、外围分布、材质和亮度变化均须复测。数学上保留比例不代表实际检测稳定；一次成功的色值、尺寸或校准系数不能推广为固定配方。

## 将反馈变成下一步决策

详细记录留在任务私有空间；当轮仅将可复用判断写入 Skill：

1. 将反馈或自审绑定到确切版本，区分用户判断与 Agent 淘汰。写明可见缺陷及位置、解码证据、仍需验证的原因。用户喜欢的图也可能仍有未解决的局限。
2. 找到出错的决策。布置信息前检查实际返回图的几何；提示词坐标和要求的物体数量不是图像事实。事后亮度补丁造成眼圈、人工斑驳或专设码面时，回到承载方式与功能几何的兼容性，不将其当作纹理问题继续涂补。
3. 最小修订相关指导，并在重试前应用。已有规则时，将检查提前到反复违规的操作之前，写出可观察证据。例如先检查接触与投影，再花时间修复可读性；修复后再独立审外观。
4. 每次重试都要有已诊断的缺陷、针对性改动和成功检查。连续尝试重现同一结构冲突时，改变信息形成机制，不延长蒙参数或付费重绘循环。结束该机制不等于停止已获授权的创作任务，应继续探索不同机制。光、反射或负形只是可选载体，不是新的默认模板。复核原缺陷及双重验收，记录未解决结果，下一轮读取本次修订。

各语言版本同步维护。不为每张图堆一条规则；没有新教训时不强行改字，而是在任务记录中说明已有指导已检查并应用。尚未通过实际完整成图验收的方法须标记为探索，不能写成已验证成功做法。
